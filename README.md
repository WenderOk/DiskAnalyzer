#### DiskAnalyzer

Кроссплатформенный анализатор файловой системы, написанный на C#. Приложение предназначено для сканирования директорий, оценки занимаемого дискового пространства и визуализации структуры файлов. 

#### Архитектура и структура проекта

Решение построено с разделением на слои и выделением фонового обработчика для ресурсоемких операций сканирования: 

* **DiskAnalyzer.Domain** — основные сущности предметной области, модели файлов, директорий и бизнес-правила.
* **DiskAnalyzer.Application** — сценарии использования (use cases), сервисы анализа и интерфейсы взаимодействия между слоями.
* **DiskAnalyzer.Infrastructure** — реализация работы с файловой системой, доступ к данным и системные интеграции.
* **DiskAnalyzer.UI** — кроссплатформенный пользовательский интерфейс для отображения результатов сканирования.
* **DiskAnalyzer.Worker** — фоновый сервис (воркер), выполняющий непосредственный обход и сбор статистики по файловой системе.
* **DiskAnalyzer.Worker.Contracts** — общие модели данных и контракты сообщений для взаимодействия между основным приложением и воркером.
* **DiskAnalyzer.Worker.Client** — клиентская библиотека для подключения и отправки задач в DiskAnalyzer.Worker.

#### Требования

* .NET 8 SDK
* Поддерживаемые ОС: Windows, Linux, macOS

#### Сборка и запуск

1. Клонируйте репозиторий: 

```bash
git clone https://github.com/WenderOk/DiskAnalyzer.git
cd DiskAnalyzer
```

2. Запустите проект: 

```bash
dotnet run --project DiskAnalyzer.UI/DiskAnalyzer.UI.csproj
```
#### Основные возможности

* Рекурсивное сканирование локальных дисков и выбранных директорий.
* Подсчет размера папок, количества файлов и распределение по типам.
* Вынесение тяжелых операций обхода файловой системы в отдельный фоновый процесс для сохранения отзывчивости интерфейса.
